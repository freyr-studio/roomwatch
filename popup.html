Roomwatch

Ton compagnon pour suivre tes cams et être alerté dès qu'un live commence.

Connecte-toi sur le site : l'extension détecte ta session automatiquement.

    Retour d'une room AFK

    Concerne les rooms de la liste AFK.

    Comment ça marche

    Toutes les rooms AFK sont surveillées, même si elles étaient déjà en live quand tu les as ajoutées. Vérification toutes les 2 minutes environ ; le bouton ⟳ de l'onglet AFK la lance tout de suite.

    Archivage automatique

    Comment ça marche

    Vérifié toutes les 6 h, ou tout de suite avec le bouton « Vérifier maintenant » de l'onglet Favoris. Seule une room dont le dernier live est connu peut être archivée.

    Roomwatch

    Mode discret

    Floute les miniatures, masque les titres, coupe les sons et rend les notifications neutres. Raccourci par défaut : Alt+Shift+H (modifiable dans chrome://extensions/shortcuts). La touche Échap ferme la fenêtre.
